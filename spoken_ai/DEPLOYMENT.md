## 📖 使用说明

### 用户视角
1. **查看记录列表**
   - 访问 `/toefl/records/`
   - 显示所有练习记录
   - 可按 Task 类型和状态筛选

2. **查看详情**
   - 点击任意记录进入详情页
   - 查看用户答案
   - 查看 AI 反馈（问题、建议、参考答案）
   - 查看分数详情
   - 查看关联的题目原文

3. **管理记录**
   - 更新状态（已完成/进行中/已复习）
   - 添加个人备注
   - 下载 PDF 报告

### 技术实现

**记录保存流程**:
```
用户提交答案 → analyse_task() → AI分析 → 生成PDF → 保存记录 → 返回结果
```

**数据提取**:
- 从 `feedback` JSON 中提取 `overall_score` 作为分数
- 整个 `feedback` 作为详细反馈保存

**权限控制**:
- 未登录用户：记录不保存，无法访问记录页
- 只能查看和修改自己的记录

## 🔗 访问路由

| 路由 | 功能 | 说明 |
|------|------|------|
| `/toefl/records/` | 记录列表 | 显示所有练习记录 |
| `/toefl/records/<id>/` | 记录详情 | 查看单条记录完整信息 |
| `/toefl/records/<id>/status/` | 更新状态 | API - 更新记录状态 |
| `/toefl/records/<id>/note/` | 添加备注 | API - 保存用户备注 |

## ⚠️ 注意事项

1. **用户未登录时** - 记录不会被保存（代码中有判断）
2. **分数提取** - 需要 AI 返回的 feedback 包含 `overall_score` 字段
3. **PDF 存储** - 保存在 `media/toefl_reports/` 目录
4. **LSP 警告** - Django 动态特性导致，不影响运行

## 📞 常见问题

**Q: 记录没有保存？**
A: 检查用户是否已登录，feedback 格式是否正确

**Q: 分数显示为 null？**
A: 确保 AI 返回的 feedback 包含 `overall_score` 字段

**Q: 无法访问记录页？**
A: 确保用户已登录

**Q: 模板样式不对？**
A: 检查 Tailwind CSS 是否正确引入
